# Магазин туров и активностей

## Цель проекта

Создать сайт в формате мобильного приложения для бронирования экскурсий, туров и других активностей с личным кабинетом клиента, кабинетом партнёра и полноценной админ-панелью.

## Основные возможности

### Просмотр и каталог активностей

- **Цель:** Клиент может просматривать активности, знакомиться с их описанием, фотографиями и ценой.
- **Описание:** На главной странице отображаются 10 последних добавленных и 10 популярных активностей в виде карточек с превью и названием. В hero-секции на главной странице показывается слайдер фоновых фотографий, которые можно добавлять и заменять из админ-панели. Каждая активность имеет отдельную страницу с уникальным адресом, где показаны фотографии, название, описание в удобном форматированном виде, цена для клиента, город или место проведения и кнопка лайка. Город/место на странице активности является ссылкой на страницу с картой этого места и списком активностей. Активности группируются по разделам, созданным администратором. Если активность помечена 18+, перед показом содержимого появляется плашка с вопросом о возрасте. Работает поиск активностей по названию, городу и разделу. На отдельной странице поиска работает ИИ-ассистент, который помогает уточнить запрос и предлагает подходящие активности. На странице активности отображается ссылка на публичный профиль партнёра, если активность добавлена партнёром. На странице активности отображается номер аттестата партнёра (если заполнен).
- **Критерии приёмки:**
  - Главная страница показывает 10 последних и 10 популярных активностей карточками
  - В hero-секции отображается слайдер фоновых фотографий
  - Слайдер автоматически переключает фото
  - Фото для слайдера можно добавлять и удалять из админ-панели
  - Каждая активность открывается на отдельной странице с уникальным URL
  - На странице активности отображаются фото, название, описание, цена для клиента, город/место
  - Город/место на странице активности является ссылкой на страницу с картой и списком активностей
  - Работает лайк — активности с большим числом лайков попадают в популярные
  - Разделы активностей выводят все активности в своей категории
  - Для активностей 18+ на странице показывается плашка с подтверждением возраста
  - Работает поиск активностей по названию, городу и разделу
  - На странице поиска есть ИИ-ассистент с диалогом для уточнения запроса
  - ИИ-ассистент задаёт уточняющие вопросы и предлагает активности
  - В диалоге ИИ-ассистента есть удобные кнопки-подсказки для выбора типа активности и бюджета
  - Результаты поиска отображаются карточками активностей
  - На странице активности есть ссылка на публичный профиль партнёра (если активность от партнёра)
  - На странице активности отображается «Аттестат: [номер]» если у партнёра заполнен номер документа

### Админ-панель

- **Цель:** Администратор может управлять контентом сайта через защищённую панель.
- **Описание:** Отдельная страница авторизации администратора по отдельному адресу. После входа доступно: добавление и редактирование активностей (название, описание в редакторе, фотографии, цена для клиента, цена для партнёра, город/место, метка 18+), создание разделов, управление календарём доступных дат и часов, настройка email-ящиков для уведомлений, выбор типа приёма заказа (оплата или форма заказа). ID разделов и активностей автоматически генерируются в транслитерации из названия. Цена для партнёра не показывается клиенту, но именно она отправляется на оплату при выборе оплаты. Главный администратор (artkmv1@ya.ru) может добавлять, редактировать и удалять других администраторов. Дополнительные администраторы имеют доступ только к управлению активностями и разделами. В админ-панели есть раздел «Новые активности», где отображаются активности, добавленные партнёрами. Администратор может одобрить или отклонить активность. При одобрении активность становится активной и показывается в каталоге. Администратор может указать цену для партнёра в виде процента от цены для клиента. В админ-панели есть разделы управления меню для админов, клиентов, партнёров и нижнего меню (footer) — можно добавлять, редактировать и удалять пункты меню (название, URL, порядок). Пункты меню отображаются в верхней шапке соответствующего интерфейса. Пункты нижнего меню отображаются в подвале (footer) на всех страницах сайта. В админ-панели есть раздел «Статистика» для управления счётчиками аналитики (Яндекс.Метрика, Google Analytics и другие). Можно добавлять код счётчика (HTML/JS), который подключается на всех страницах сайта, включая админ-панель и личные кабинеты. В админ-панели есть раздел «Отчёты» со списком всех заказов с пагинацией (100 на страницу), поиском по номеру заказа и детальной информацией при нажатии на заказ (партнёр, клиент, дата, время, цена). В админ-панели есть раздел «Отзывы» для модерации отзывов на активности. В админ-панели есть раздел «Слайдер» для управления фоновыми фотографиями hero-секции на главной странице. В админ-панели есть раздел «Варианты заказа» с глобальным переключателем, который разрешает или запрещает использование формы заказа для активностей. Если форма заказа запрещена глобально, то для всех новых активностей по умолчанию устанавливается тип приёма заказа «оплата». В списке партнёров в админ-панели можно индивидуально разрешить форму заказа для конкретного партнёра. В списке партнёров в админ-панели при нажатии на партнёра отображаются его анкетные и юридические данные.

### Личный кабинет клиента

- **Цель:** Клиент может регистрироваться, входить и управлять своими бронированиями.
- **Описание:** Отдельная страница авторизации по отдельному адресу. При первом входе — регистрация с именем, номером телефона, email и паролем. Вход по email и паролю. Также доступен вход через ВКонтакте (VK ID). После бронирования клиент попадает на страницу подтверждения в личном кабинете. Письмо с данными регистрации отправляется на email. Администратор может просматривать, редактировать и удалять клиентов. В верхней шапке личного кабинета отображаются пункты меню из раздела «Меню для клиентов». В личном кабинете есть раздел «Мои бронирования» со списком всех броней с фильтрацией по статусу и дате. Клиент может оставлять отзывы на активности. Клиент получает уведомления на сайте об изменении статуса брони. В разделе «Уведомления и чат» клиент видит список уведомлений и чат с партнёром по каждому подтверждённому заказу. В настройках клиента есть переключатель «Получать уведомления ВКонтакте» — если включён, уведомления дублируются в личные сообщения ВК через VK API.
- **Критерии приёмки:**
  - Страница входа клиента доступна по отдельному URL
  - Регистрация: имя, телефон, email, пароль
  - Вход по email и паролю
  - На странице входа есть кнопка «Войти через ВКонтакте»
  - После авторизации через ВК создаётся или привязывается аккаунт клиента
  - После бронирования открывается страница подтверждения в личном кабинете
  - Письмо с регистрационными данными уходит на email клиента
  - В админ-панели есть раздел «Клиенты» со списком всех клиентов
  - Администратор может редактировать данные клиента
  - Администратор может удалять клиентов
  - Пункты меню для клиентов отображаются в верхней шапке личного кабинета
  - В личном кабинете есть раздел «Мои бронирования» со списком всех броней
  - Работает фильтрация броней по статусу и дате
  - Клиент может оставлять отзывы на активности
  - Клиент получает уведомления на сайте об изменении статуса брони
  - В разделе «Уведомления и чат» отображаются уведомления и чат по заказам
  - В настройках клиента есть переключатель «Получать уведомления ВКонтакте»
  - При включённом переключателе уведомления отправляются в ЛС ВК

- **Описание:** На странице активности отображается календарь с доступными датами, которые настроил администратор. Если для даты отмечены часы — показываются доступные часы. Если часы не отмечены — доступен весь день. После выбора клиент переходит к оформлению: либо на страницу оплаты (Т-банк), либо на форму заказа (в зависимости от настройки активности). Форма заказа содержит название активности, выбранную дату, время (если есть), имя, телефон и поле «Мои подробности». Кнопка «Забронировать» отправляет письмо на email администратора. При оплате используется цена для партнёра. Если клиент забронировал дату или часы, они автоматически становятся недоступны для других клиентов. Каждому заказу присваивается уникальный номер.
- **Критерии приёмки:**
  - На странице активности отображается календарь с доступными датами
  - Если администратор отметил часы — они показываются для выбора
  - Если часы не отмечены — доступен весь день
  - После выбора даты/времени открывается страница оформления
  - В зависимости от настройки активности: страница оплаты Т-банк или форма заказа
  - Форма заказа содержит все необходимые поля и кнопку «Забронировать»
  - После отправки формы письмо уходит на email администратора
  - При оплате используется цена для партнёра
  - Забронированные даты и часы скрываются из календаря для других клиентов
  - Каждому заказу присваивается уникальный номер

### Оплата через Т-банк

- **Цель:** Клиент может оплатить бронирование онлайн через платёжную систему Т-банка.
- **Описание:** Интеграция с платёжной системой Т-банка. На странице оплаты отображается окно для ввода платёжных данных. После успешной оплаты бронирование подтверждается. Сумма оплаты берётся из цены для партнёра.
- **Критерии приёмки:**
  - Страница оплаты интегрирована с Т-банком
  - После успешной оплаты бронирование подтверждается
  - При ошибке оплаты клиент видит соответствующее сообщение
  - Сумма оплаты соответствует цене для партнёра

### Отзывы и рейтинг

- **Цель:** Клиенты могут оставлять отзывы на активности с оценкой. Отзывы проходят модерацию в админ-панели.

В админ-панели есть раздел «Отзывы» со списком всех отзывов, где можно одобрить или отклонить. На странице активности отображается средний рейтинг и количество отзывов.
- **Критерии приёмки:**
  - Клиент может оставить отзыв с текстом и оценкой на странице активности
  - Отзыв отображается только после одобрения администратором
  - В админ-панели есть раздел «Отзывы» для модерации
  - На странице активности отображается средний рейтинг и количество отзывов

### Уведомления и чат

- **Цель:** Клиент и партнёр получают уведомления и могут общаться в чате по каждому заказу.
- **Описание:** В личном кабинете клиента и партнёра есть раздел «Уведомления и чат» со списком уведомлений и чатом по каждому заказу. Клиент получает уведомления об изменении статуса брони. Партнёр получает уведомления о новых заказах и изменении статуса активности. Чат между клиентом и партнёром доступен с момента подтверждения заказа и до его выполнения. В чате можно отправлять текстовые сообщения. Если пользователь включил уведомления ВКонтакте в настройках, уведомления также отправляются в личные сообщения ВК через VK API.
- **Критерии приёмки:**
  - В личном кабинете клиента есть раздел «Уведомления и чат»
  - В кабинете партнёра есть раздел «Уведомления и чат»
  - Уведомления отображаются списком с датой и текстом
  - Для каждого подтверждённого заказа доступен чат с собеседником
  - Чат активен с момента подтверждения заказа до выполнения
  - Можно отправлять и просматривать сообщения в чате
  - Если включены уведомления ВК, они дублируются в ЛС ВКонтакте

### SEO и производительность

- **Цель:** Страницы активностей и публичные страницы оптимизированы для поисковых систем и имеют хорошую производительность.
- **Описание:** Каждая страница активности имеет уникальные SEO-метаданные (title, description, Open Graph, Twitter Cards) на основе данных активности. Создана карта сайта (sitemap.xml) для поисковых систем. Реализована поддержка PWA (Progressive Web App) с манифестом, service worker, поддержкой офлайн-режима и подсказками по установке на Android и iOS.
- **Критерии приёмки:**
  - Каждая страница активности имеет уникальный SEO-заголовок и мета-описание
  - Работают Open Graph и Twitter Cards для страниц активностей
  - Создан sitemap.xml со всеми публичными страницами
  - Сайт работает как PWA: есть манифест, service worker, иконки
  - На Android появляется подсказка установки приложения
  - На iOS появляется подсказка «Добавить на экран «Домой»
  - Приложение работает офлайн (кэширование через service worker)
