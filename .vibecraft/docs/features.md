# Магазин туров и активностей

## Цель проекта

Создать сайт в формате мобильного приложения для бронирования экскурсий, туров и других активностей с личным кабинетом клиента, кабинетом партнёра, кабинетом агента (партнёрская программа) и полноценной админ-панелью. Сайт также позволяет размещать объявления по аренде жилья (услуги): номера в отелях/хостелах, квартиры, дома, коттеджи и отдельные комнаты.

## Основные возможности

### Просмотр и каталог активностей

- **Цель:** Клиент может просматривать активности, знакомиться с их описанием, фотографиями и ценой.
- **Описание:** На главной странице отображаются 10 последних добавленных и 10 популярных активностей в виде карточек с превью и названием. В hero-секции на главной странице показывается слайдер фоновых фотографий, которые можно добавлять и заменять из админ-панели. Каждая активность имеет отдельную страницу с уникальным адресом, где показаны фотографии, название, описание в удобном форматированном виде, цена для клиента, город или место проведения и кнопка лайка. Город/место на странице активности является ссылкой на страницу с картой этого места и списком активностей. Активности группируются по разделам, созданным администратором. Если активность помечена 18+, перед показом содержимого появляется плашка с вопросом о возрасте. Работает поиск активностей по названию, городу и разделу. На отдельной странице поиска работает ИИ-ассистент, который помогает уточнить запрос и предлагает подходящие активности. В верхней шапке сайта есть селектор города: по нажатию открывается выпадающая панель с полем поиска и списком городов, при вводе список фильтруется по введённому тексту, выбор сохраняется в браузере и при выборе города происходит переход на главную страницу сервиса my.magazin-tour.ru с параметром ?city=<слаг> (например https://my.magazin-tour.ru/?city=pyatigorsk), где слаг города формируется в латинской транслитерации без русских символов. На странице активности отображается ссылка на публичный профиль партнёра, если активность добавлена партнёром. На странице активности отображается номер аттестата партнёра (если заполнен). Разделы отображаются на сайте (на главной, в навигации и на страницах разделов) только если в них есть хотя бы одна активная активность; пустые разделы автоматически скрываются.
- **Критерии приёмки:**
  - Главная страница показывает 10 последних и 10 популярных активностей карточками
  - В hero-секции отображается слайдер фоновых фотографий
  - Слайдер автоматически переключает фото
  - Фото для слайдера можно добавлять и удалять из админ-панели
  - Фотографии в слайдере отображаются корректно во всех браузерах (без серого фона вместо фото)
  - Каждая активность открывается на отдельной странице с уникальным URL
  - На странице активности отображаются фото, название, описание, цена для клиента, город/место
  - Город/место на странице активности является ссылкой на страницу с картой и списком активностей
  - Работает лайк — активности с большим числом лайков попадают в популярные; ставить лайк могут только зарегистрированные клиенты (для незарегистрированных показывается предложение зарегистрироваться)
  - Разделы активностей выводят все активности в своей категории
  - Разделы, в которых нет ни одной активной активности, не отображаются на сайте (на главной, в навигации и на страницах разделов)
  - Для активностей 18+ на странице показывается плашка с подтверждением возраста
  - Работает поиск активностей по названию, городу и разделу
  - На странице поиска есть ИИ-ассистент с диалогом для уточнения запроса
  - ИИ-ассистент задаёт уточняющие вопросы и предлагает активности
  - В диалоге ИИ-ассистента есть удобные кнопки-подсказки для выбора типа активности и бюджета
  - Результаты поиска отображаются карточками активностей
  - На странице активности есть ссылка на публичный профиль партнёра (если активность от партнёра)
  - На странице активности отображается «Аттестат: [номер]» если у партнёра заполнен номер документа

### Админ-панель

- **Цель:** Администратор может управлять контентом сайта через защищённую панель.
- **Описание:** Отдельная страница авторизации администратора по отдельному адресу. После входа доступно: добавлени�� и редактирование активностей (название, описание в редакторе, фотографии, цена для клиента, цена для партнёра, город/место, метка 18+, языки проведения (на каких языках проводится активность — можно выбрать несколько, по умолчанию русский)), создание и редактирование разделов, управление календарём доступных дат и часов, настройка email-ящиков для уведомлений, выбор типа приёма заказа (оплата или форма заказа). ID разделов и активностей автоматически генерируются в транслитерации из названия. Цена для партнёра не показывается клиенту, но именно она отправляется на оплату при выборе оплаты. Главный администратор (artkmv1@ya.ru) может добавлять, редактировать и удалять других администраторов. Дополнительные администраторы имеют доступ только к управлению активностями и разделами. В админ-панели есть раздел «Новые активности», где отображаются активности, добавленные партнёрами. Администратор может одобрить или отклонить активность. При одобрении активность становится активной и показывается в каталоге. Администратор может указать цену для партнёра в виде процента от цены для клиента. В админ-панели есть разделы управления меню для админов, клиентов, партнёров и нижнего меню (footer) — можно добавлять, редактировать и удалять пункты меню (название, URL, порядок). Пункты меню отображаются в верхней шапке соответствующего интерфейса. Пункты нижнего меню отображаются в подвале (footer) на всех страницах сайта. В админ-панели есть раздел «Статистика» для управления счётчиками аналитики (Яндекс.Метрика, Google Analytics и другие). Можно добавлять код счётчика (HTML/JS), который подключается на всех страницах сайта, включая админ-панель и личные кабинеты. В админ-панели есть раздел «Отчёты» со списком всех заказов с пагинацией (100 на страницу), поиском по номеру заказа и детальной информацией при нажатии на заказ (партнёр, клиент, дата, время, цена). В админ-панели есть раздел «Отзывы» для модерации отзывов на активности. В админ-панели есть раздел «Слайдер» для управления фоновыми фотографиями hero-секции на главной странице. В админ-панели есть раздел «Варианты заказа» с глобальным переключателем, который разрешает или запрещает использование формы заказа для активностей. Если форма заказа запрещена глобально, то для всех новых активностей по умолчанию устанавливается тип приёма заказа «оплата». В списке партнёров в админ-панели можно индивидуально разрешить форму заказа для конкретного партнёра. В списке партнёров в админ-панели при нажатии на партнёра отображаются его анкетные и юридические данные.
- **Критерии приёмки:**
  - Админ-панель доступна по отдельному URL с отдельной страницей входа
  - Администратор может создавать, редактировать и удалять активности
  - Работает редактор описания (WYSIWYG)
  - Можно загружать фотографии для активностей
  - Можно создавать и редактировать разделы и назначать активности в разделы
  - ID разделов и активностей создаются в транслитерации из названия
  - Администратор управляет календарём: отмечает доступные даты и часы
  - Администратор может закрывать открытый день или несколько дней (и часы в них) от новых заказов
  - При закрытии дня с существующими заказами администратор предупреждается о наличии заказов
  - Настраивается тип приёма заказа (оплата / форма) для каждой активности
  - Можно управлять email-ящиками для уведомлений
  - При создании/редактировании активности есть переключатель 18+
  - При создании/редактировании активности есть поле «Город / место»
  - При создании/редактировании активности есть поле «На каких языках проводится активность?» с выбором нескольких языков, по умолчанию «русский»
  - При создании/редактировании активности есть поле «Цена для партнёра»
  - Цена для партнёра не отображается на странице клиента
  - При оплате списывается цена для партнёра
  - Главный администратор может добавлять, редактировать и удалять других администраторов
  - Дополнительные администраторы видят только активности и разделы
  - В админ-панели есть раздел «Новые активности» со списком активностей от партнёров
  - Администратор может одобрить активность — она становится активной в каталоге
  - Администратор может отклонить активность
  - Администратор может указать цену для партнёра в % от цены клиента
  - В админ-панели есть разделы управления меню для админов, клиентов, партнёров и нижнего меню
  - Пункты меню для админов отображаются в верхней шапке админ-панели
  - Пункты меню для клиентов отображаются в верхней шапке личного кабинета
  - Пункты меню для партнёров отображаются в верхней шапке кабинета партнёра
  - Пункты нижнего меню отображаются в подвале (footer) на всех страницах сайта
  - В админ-панели есть раздел «Статистика» для управления счётчиками
  - Можно добавлять код счётчика (HTML/JS)
  - Можно удалять счётчики
  - Код счётчиков подключается на всех страницах сайта
  - В админ-панели есть раздел «Отчёты» со списком заказов с пагинацией 100 на страницу
  - Каждому заказу присвоен номер
  - Работает поиск по номеру заказа
  - При нажатии на заказ отображается информация о партнёре, клиенте, дате, времени и цене
  - В админ-панели есть раздел «Отзывы» для модерации отзывов
  - В админ-панели есть раздел «Слайдер» для управления фоновыми фото hero-секции
  - Можно добавлять фото для слайдера
  - Можно удалять фото из слайдера
  - Фото отображаются в hero-секции на главной странице
  - В админ-панели есть раздел «Варианты заказа» с глобальным переключателем
  - При выключенном переключателе формы заказа новые активности создаются только с типом «оплата»
  - В списке партнёров в админ-панели можно индивидуально разрешить форму заказа для конкретного партнёра
  - В списке партнёров в админ-панели при нажатии на партнёра отображаются его анкетные и юридические данные
  - В отчётах админ-панели отображается порядковый номер каждого заказа
  - В отчётах админ-панели есть подраздел «Отмена активностей» с отменёнными оплаченными активностями
  - В отчётах админ-панели есть подраздел «Архив» с удалёнными заказами и плашкой об удалении
  - Весь поток активностей (все заказы) отображается в разделе «Отчёты»

### Личный кабинет клиента

- **Цель:** Клиент может регистрироваться, входить и управлять своими бронированиями.
- **Описание:** Отдельная страница авторизации по отдельному адресу. При первом входе — регистрация с именем, номером телефона, email и паролем. Вход по email и паролю. Также доступен вход через ВКонтакте (VK ID). После бронирования клиент попадает на страницу подтверждения в личном кабинете. Письмо с данными регистрации отправляется на email. Администратор может просматривать, редактировать и удалять клиентов. В верхней шапке личного кабинета отображаются пункты меню из раздела «Меню для клиентов». В личном кабинете есть раздел «Мои бронирования» со списком всех броней с фильтрацией по статусу и дате. Клиент может оставлять отзывы на активности. Клиент получает уведомления на сайте об изменении статуса брони. В разделе «Уведомления и чат» клиент видит список уведомлений и чат с партнёром по каждому подтверждённому заказу. В настройках клиента есть переключатели «Получат�� уведомления ВКонтакте» и «Получать уведомления в Telegram» — если включены, уведомления дублируются в соответствующие каналы. На дашборде клиента отображаются 5 последних уведомлений из заказов со статусами. На дашборде клиента отображается информация из раздела «Информация туристам».
- **Критерии приёмки:**
  - Страница входа клиента доступна по отдельному URL
  - Регистрация: имя, телефон, email, пароль
  - Вход по email и паролю
  - На странице входа есть кнопка «Войти через ВКонтакте»
  - После авторизации через ВК создаётся или привязывается аккаунт клиента
  - После бронирования открывается страница подтверждения в личном кабинете
  - Письмо с регистрационными данными уходит на email клиента
  - В админ-панели есть раздел «Клиенты» со списком всех клиентов
  - Администратор может редактировать данные клиента
  - Администратор может удалять клиентов
  - Пункты меню для клиентов отображаются в верхней шапке личного кабинета
  - В личном кабинете есть раздел «Мои бронирования» со списком всех броней
  - Работает фильтрация броней по статусу и дате
  - Клиент может оставлять отзывы на активности
  - Клиент получает уведомления на сайте об изменении статуса брони
  - В разделе «Уведомления и чат» отображаются уведомления и чат по заказам
  - В настройках клиента есть переключатель «Получать уведомления ВКонтакте»
  - При включённом переключателе уведомления отправляются в ЛС ВК
  - В настройках клиента есть переключатель «Получать уведомления в Telegram»
  - При включённом переключателе уведомления отправляются в Telegram
  - Клиент может удалять свой заказ, при этом партнёр получает уведомление об удалении
  - В «Мои бронирования» клиента отображается сумма «Партнеру на руки после выполнения активности вы должны отдать ... руб.» — сумма за минусом партнёрской комиссии; для активностей с типом приёма заказа «форма заказа» указывается вся сумма целиком (без вычета)
  - В «Мои бронирования» клиента есть подраздел «Архив» с удалёнными заказами
  - В списке бронирований клиента отображается порядковый номер заказа
  - На дашборде клиента отображаются 5 последних уведомлений из заказов со статусами
  - На дашборде клиента отображается информация из раздела «Информация туристам» (вместо старого блока «Информация для туристов»)

### Кабинет партнёра

- **Цель:** Партнёр может регистрироваться, входить, добавлять активности и управлять заказами.
- **Описание:** Отдельная страница авторизации и регистрации по отдельному адресу. После входа доступны разделы:
  - **Добавить активность** — форма добавления активности (название, описание, фото, цена для клиента, город/место, раздел, метка 18+). Без поля «Цена для партнёра». Добавленные активности попадают в раздел «Новые активности» в админ-панели на модерацию.
  - **Мои активности** — список активностей, добавленных партнёром, с указанием статуса (на модерации / одобрена / отклонена). Партнёр может редактировать свои активности, включая календарь доступных дат и часов.
  - **Заказы** — список заказов на активности партнёра от клиентов. Партнёр может удалять заказы, при этом клиент получает уведомление об удалении. Удалённые заказы попадают в подраздел «Архив».
  - **Календарь** — календарь с отмеченными активными заказами. При нажатии на дату с заказами отображается информация: кто заказал, какая активность и во сколько. При нажатии на заказ — переход на информацию в разделе «Заказы». Партнёр может закрывать открытый день или несколько дней (и часы в них) от новых заказов; при закрытии дня с существующими заказами партнёр предупреждается, существующие заказы не удаляются, но новые в закрытые дни оформить нельзя.
  - **Как работать с Магазином туров?** — ссылка на https://magazin-tour.ru/kak-rabotat-s-magazinom-turov/
  - **Публичный профиль** — страница редактирования публичного профиля партнёра: фото, описание (WYSIWYG-редактор TipTap), slug (английское имя страницы). Публичный профиль доступен по отдельному URL /partners/[slug] для всех посетителей сайта. На странице профиля отображаются фото, описание и список активностей партнёра.   - Пересчёт лесенки выполняется раз в месяц
  - Агентский процент закладывается в процент партнёра при модерации (отнимается от доли партнёра)
  - При отмене оплаченной активности начисленная агентская комиссия уменьшается на эту сумму
  - Агент может подать заявку на вывод заработка (раз в месяц) в разделе «Заработок и выплаты»
  - В разделе «Заработок и выплаты» отображаются актуальная сумма и помесячные цифры
  - У каждой заявки на выплату есть порядковый номер, видимый агенту и администратору
  - После подтверждения выплаты администратором агент видит пометку «ожидайте выплату»

### Админ-панель: Агенты, Информация агентам, Выплаты агентам

- **Цель:** Администратор может управлять агентами, информацией для агентов и выплатами.
- **Описание:** В админ-панели появляются три раздела.
  - **Агенты** — списком выводятся зарегистрированные агенты. При нажатии на агента выводится важная информация о нём и список зарегистрированных через него партнёров. Администратор может заблокировать/разблокировать агента. В этом разделе задаются пороги лесенки 3-4-5% (в рублях) и пересчёт процентов.
  - **Информация агентам** — редактор и список материалов (по аналогии с «Информация для партнёров»/«Информация для туристов»). Материалы выводятся на дашборде агента.
  - **Выплаты агентам** — заявки на выплаты от агентов с кнопками «Выплатить» и «Отказать». При нажатии «Выплатить» появляется маркировка «надо выплатить» и формируется платёжка для выплаты, у агента появляется значок «ожидайте выплату». После нажатия «Выплатить» появляется кнопка «Выплата произведена». При её нажатии выплата уходит в архив. Все выплаты имеют порядковый номер и показываются в разделе в админке и у агента.
- **Критерии приёмки:**
  - В админ-панели есть раздел «Агенты»
  - В разделе «Агенты» списком выводятся зарегистрированные агенты
  - При нажатии на агента отображается важная информация о нём и список его партнёров
  - Администратор может заблокировать/разблокировать агента
  - В раз��еле «Агенты» задаются пороги лесенки 3-4-5% (в рублях)
  - В админ-панели есть раздел «Информация агентам» с редактором и списком материалов
  - Материалы из раздела «Информация агентам» выводятся на дашборде агента
  - В админ-панели есть раздел «Выплаты агентам»

### Объявления (услуги жилья)

- **Цель:** Партнёры могут размещать объявления по аренде жилья (номера в отелях/хостелах, квартиры, дома, коттеджи, отдельные комнаты), а клиенты — находить и бронировать их. Объявления — отдельная сущность, не смешивается с активностями.
- **Описание:** Объявления — это отдельный раздел сайта «Снять что угодно» для аренды жилья. Сущность полностью независима от активностей: отдельные таблицы, отдельные API, отдельный раздел админки и отдельный каталог. Общий каркас сайта (шапка, селектор города, единая навигация) используется совместно. В шапке есть переключатель «Активности / Жильё».
  - При добавлении объявления партнёр выбирает, что будет сдавать: **Номера / спальные места** (гостиница, отель, бутик-отель, мини-гостиница, отель эконом-класса, апартамент, апарт-отель, хостел, капсульный отель, паломнический отель, база отдыха, гостевой дом, кемпинг, глэмпинг, эко-отель, парк-отель, пансионат, санаторий), **Квартиры / апартаменты целиком** (квартира, апартамент, студия), **Дома / коттеджи целиком** (коттедж, эллинг, гестхаус, особняк, дом, деревенский дом, шале, яхта, вилла, таунхаус, бунгало, дача, частный дом с отдельным входом, целый этаж в доме, дом на колёсах) или **Отдельные комнаты** (комната в квартире, комната в частном доме, комната в коттедже).

  - Для квартир/домов/комнат целиком форма начинается с адреса и карты для точного определения места, затем Основная информация, затем Фото и цена.

После одобрения администратором объявление становится активным и появляется в разделе «Снять что угодно» на сайте (раздел появляется, когда в городе или месте есть хотя бы одно активное объявление).

  - Синхронизация с менеджерами каналов (realtycalendar, travelline, bnovo, Агаст) реализуется отдельным этапом после ядра; архитектура проектируется с запасом, чтобы каналы подключались позже без переделки.
- **Критерии приёмки:**
  - В кабинете партнёра есть пункты «Добавить объявление» и «Мои объявления»
  - При добавлении объявления партнёр выбирает тип: номера/спальные места, квартиры/апартаменты, дома/коттеджи, отдельные комнаты
  - Для номеров/спальных мест доступен выбор подтипа (гостиница, отель, бутик-отель, мини-гостиница, отель эконом-класса, апартамент, апарт-отель, хостел, капсульный отель, паломнический отель, база отдыха, гостевой дом, кемпинг, глэмпинг, эко-отель, парк-отель, пансионат, санаторий)
  - Для квартир/апартаментов доступен выбор подтипа (квартира, апартамент, студия)

- Синхронизация с менеджерами каналов (realtycalendar, travelline, bnovo, Агаст) — двухсторонняя, реализуется отдельным этапом после ядра; архитектура проектируется с запасом для подключения каналов без переделки

### Жёсткие правила

Постоянные правила проекта, которые соблюдаются автоматически, без вопросов
к пользователю. Полный список механизмов описан в `RULES.md` в корне
репозитория.

1. **НИЧЕГО НИКОГДА НИКУДА НЕ ПРОПАДАЕТ.** Загружаемые файлы (аватарки
   партнёров, фото активностей, фото слайдера hero) и любые данные надёжно
   хранятся. `public/uploads/` авто-коммитится в git при каждом деплое,
   а также создаётся периодический бэкап загружаемых файлов в отдельную папку
   `backups/uploads/`, которую деплой не удаляет и не перезатирает. Ни один
   загруженный пользователем файл не теряется при пересоздании сервера,
   пересборке или деплое.
2. **БАЗЫ ВСЕГДА В РАБОЧЕМ СОСТОЯНИИ.** При каждом деплое и при запуске
   автоматически проверяется доступность БД (DynamoDB), схема всех таблиц
   (ключи и GSI) сверяется с кодом, прогоняются миграции и исправляются
   несоответствия (пересоздание таблиц с неверным ключом, добавление
   недостающих GSI). Проверка запускается автоматически как часть процесса
   деплоя (`npm run db:check`).
3. **НИКОГДА НЕ СПРАШИВАТЬ «ЕСТЬ ЛИ ОНИ?».** Ассистент и автоматика всегда
   исходят из того, что база, загруженные файлы и данные существуют и должны
   быть в рабочем состоянии. Состояние проверяется и приводится в рабочее
   состояние автоматически, без вопросов пользователю о наличии чего-либо.
