# magazin-tour

## Цель проекта

Создать сайт в формате мобильного приложения для бронирования экскурсий, туров и других активностей с личным кабинетом клиента и полноценной админ-панелью.

## Основные возможности

### Просмотр и каталог активностей

- **Цель:** Клиент может просматривать активности, знакомиться с их описанием, фотографиями и ценой.
- **Описание:** На главной странице отображаются 10 последних добавленных и 10 популярных активностей в виде карточек с превью и названием. Каждая активность имеет отдельную страницу с уникальным адресом, где показаны фотографии, название, описание в удобном форматированном виде, цена и кнопка лайка. Активности группируются по разделам, созданным администратором.
- **Критерии приёмки:**
  - Главная страница показывает 10 последних и 10 популярных активностей карточками
  - Каждая активность открывается на отдельной странице с уникальным URL
  - На странице активности отображаются фото, название, описание, цена
  - Работает лайк — активности с большим числом лайков попадают в популярные
  - Разделы активностей выводят все активности в своей категории

### Админ-панель

- **Цель:** Администратор может управлять контентом сайта через защищённую панель.
- **Описание:** Отдельная страница авторизации администратора по отдельному адресу. После входа доступно: добавление и редактирование активностей (название, описание в редакторе, фотографии, цена), создание разделов, управление календарём доступных дат и часов, настройка email-ящиков для уведомлений, выбор типа приёма заказа (оплата или форма заказа).
- **Критерии приёмки:**
  - Админ-панель доступна по отдельному URL с отдельной страницей входа
  - Администратор может создавать, редактировать и удалять активности
  - Работает редактор описания (WYSIWYG)
  - Можно загружать фотографии для активностей
  - Можно создавать разделы и назначать активности в разделы
  - Администратор управляет календарём: отмечает доступные даты и часы
  - Настраивается тип приёма заказа (оплата / форма) для каждой активности
  - Можно управлять email-ящиками для уведомлений

### Личный кабинет клиента

- **Цель:** Клиент может регистрироваться, входить и управлять своими бронированиями.
- **Описание:** Отдельная страница авторизации по отдельному адресу. При первом входе — регистрация с именем, номером телефона, email и паролем. Вход по email и паролю. После бронирования клиент попадает на страницу подтверждения в личном кабинете. Письмо с данными регистрации отправляется на email.
- **Критерии приёмки:**
  - Страница входа клиента доступна по отдельному URL
  - Регистрация: имя, телефон, email, пароль
  - Вход по email и паролю
  - После бронирования открывается страница подтверждения в личном кабинете
  - Письмо с регистрационными данными уходит на email клиента

### Календарь и бронирование

- **Цель:** Клиент может выбрать доступную дату и время для активности и оформить бронь.
- **Описание:** На странице активности отображается календарь с доступными датами, которые настроил администратор. Если для даты отмечены часы — показываются доступные часы. Если часы не отмечены — доступен весь день. После выбора клиент переходит к оформлению: либо на страницу оплаты (Т-банк), либо на форму заказа (в зависимости от настройки активности). Форма заказа содержит название активности, выбранную дату, время (если есть), имя, телефон и поле «Мои подробности». Кнопка «Забронировать» отправляет письмо на email администратора.
- **Критерии приёмки:**
  - На странице активности отображается календарь с доступными датами
  - Если администратор отметил часы — они показываются для выбора
  - Если часы не отмечены — доступен весь день
  - После выбора даты/времени открывается страница оформления
  - В зависимости от настройки активности: страница оплаты Т-банк или форма заказа
  - Форма заказа содержит все необходимые поля и кнопку «Забронировать»
  - После отправки формы письмо уходит на email администратора

### Оплата через Т-банк

- **Цель:** Клиент может оплатить бронирование онлайн через платёжную систему Т-банка.
- **Описание:** Интеграция с платёжной системой Т-банка. На странице оплаты отображается окно для ввода платёжных данных. После успешной оплаты бронирование подтверждается.
- **Критерии приёмки:**
  - Страница оплаты интегрирована с Т-банком
  - После успешной оплаты бронирование подтверждается
  - При ошибке оплаты клиент видит соответствующее сообщение

## Дополнительные заметки

- Стиль интерфейса: современный тревел — чистый, светлый дизайн с крупными фотографиями, плавными анимациями и акцентным зелёно-голубым цветом
- Сайт в формате мобильного приложения (mobile-first дизайн)
- В шапке сайта отображается: «magazin-tour. Магазин туров и активностей»
- Администратор может выбирать для каждой активности: отправлять на страницу оплаты либо на форму заказа (ползунок в настройках активности)
- Email-уведомления: письмо с регистрационными данными клиенту, письмо с данными бронирования администратору
- Администратор может добавить несколько email-ящиков для получения уведомлений
- Основные данные (email-ящики, настройки) редактируются на специальной странице в админ-панели
