# magazin-tour

## Цель проекта

Создать сайт в формате мобильного приложения для бронирования экскурсий, туров и других активностей с личным кабинетом клиента и полноценной админ-панелью.

## Основные возможности

### Просмотр и каталог активностей

- **Цель:** Клиент может просматривать активности, знакомиться с их описанием, фотографиями и ценой.
- **Описание:** На главной странице отображаются 10 последних добавленных и 10 популярных активностей в виде карточек с превью и названием. Каждая активность имеет отдельную страницу с уникальным адресом, где показаны фотографии, название, описание в удобном форматированном виде, цена для клиента, город или место проведения и кнопка лайка. Активности группируются по разделам, созданным администратором. Если активность помечена 18+, перед показом содержимого появляется плашка с вопросом о возрасте.
- **Критерии приёмки:**
  - Главная страница показывает 10 последних и 10 популярных активностей карточками
  - Каждая активность открывается на отдельной странице с уникальным URL
  - На странице активности отображаются фото, название, описание, цена для клиента, город/место
  - Работает лайк — активности с большим числом лайков попадают в популярные
  - Разделы активностей выводят все активности в своей категории
  - Для активностей 18+ на странице показывается плашка с подтверждением возраста

### Админ-панель

- **Цель:** Администратор может управлять контентом сайта через защищённую панель.
- **Описание:** Отдельная страница авторизации администратора по отдельному адресу. После входа доступно: добавление и редактирование активностей (название, описание в редакторе, фотографии, цена для клиента, цена для партнёра, город/место, метка 18+), создание разделов, управление календарём доступных дат и часов, настройка email-ящиков для уведомлений, выбор типа приёма заказа (оплата или форма заказа). ID разделов и активностей автоматически генерируются в транслитерации из названия. Цена для партнёра не показывается клиенту, но именно она отправляется на оплату при выборе оплаты. Главный администратор (artkmv1@ya.ru) может добавлять, редактировать и удалять других администраторов. Дополнительные администраторы имеют доступ только к управлению активностями и разделами.
- **Критерии приёмки:**
  - Админ-панель доступна по отдельному URL с отдельной страницей входа
  - Администратор может создавать, редактировать и удалять активности
  - Работает редактор описания (WYSIWYG)
  - Можно загружать фотографии для активностей
  - Можно создавать разделы и назначать активности в разделы
  - ID разделов и активностей создаются в транслитерации из названия
  - Администратор управляет календарём: отмечает доступные даты и часы
  - Настраивается тип приёма заказа (оплата / форма) для каждой активности
  - Можно управлять email-ящиками для уведомлений
  - При создании/редактировании активности есть переключатель 18+
  - При создании/редактировании активности есть поле «Город / место»
  - При создании/редактировании активности есть поле «Цена для партнёра»
  - Цена для партнёра не отображается на странице клиента
  - При оплате списывается цена для партнёра
  - Главный администратор может добавлять, редактировать и удалять других администраторов
  - Дополнительные администраторы видят только активности и разделы

### Личный кабинет клиента

- **Цель:** Клиент может регистрироваться, входить и управлять своими бронированиями.
- **Описание:** Отдельная страница авторизации по отдельному адресу. При первом входе — регистрация с именем, номером телефона, email и паролем. Вход по email и паролю. После бронирования клиент попадает на страницу подтверждения в личном кабинете. Письмо с данными регистрации отправляется на email. Администратор может просматривать, редактировать и удалять клиентов.
- **Критерии приёмки:**
  - Страница входа клиента доступна по отдельному URL
  - Регистрация: имя, телефон, email, пароль
  - Вход по email и паролю
  - После бронирования открывается страница подтверждения в личном кабинете
  - Письмо с регистрационными данными уходит на email клиента
  - В админ-панели есть раздел «Клиенты» со списком всех клиентов
  - Администратор может редактировать данные клиента
  - Администратор может удалять клиентов

### Календарь и бронирование

- **Цель:** Клиент может выбрать доступную дату и время для активности и оформить бронь.
- **Описание:** На странице активности отображается календарь с доступными датами, которые настроил администратор. Если для даты отмечены часы — показываются доступные часы. Если часы не отмечены — доступен весь день. После выбора клиент переходит к оформлению: либо на страницу оплаты (Т-банк), либо на форму заказа (в зависимости от настройки активности). Форма заказа содержит название активности, выбранную дату, время (если есть), имя, телефон и поле «Мои подробности». Кнопка «Забронировать» отправляет письмо на email администратора. При оплате используется цена для партнёра.
- **Критерии приёмки:**
  - На странице активности отображается календарь с доступными датами
  - Если администратор отметил часы — они показываются для выбора
  - Если часы не отмечены — доступен весь день
  - После выбора даты/времени открывается страница оформления
  - В зависимости от настройки активности: страница оплаты Т-банк или форма заказа
  - Форма заказа содержит все необходимые поля и кнопку «Забронировать»
  - После отправки формы письмо уходит на email администратора
  - При оплате используется цена для партнёра

### Оплата через Т-банк

- **Цель:** Клиент может оплатить бронирование онлайн через платёжную систему Т-банка.
- **Описание:** Интеграция с платёжной системой Т-банка. На странице оплаты отображается окно для ввода платёжных данных. После успешной оплаты бронирование подтверждается. Сумма оплаты берётся из цены для партнёра.
- **Критерии приёмки:**
  - Страница оплаты интегрирована с Т-банком
  - После успешной оплаты бронирование подтверждается
  - При ошибке оплаты клиент видит соответствующее сообщение
  - Сумма оплаты соответствует цене для партнёра

## Дополнительные заметки

- Стиль интерфейса: современный тревел — чистый, светлый дизайн с крупными фотографиями, плавными анимациями и акцентным зелёно-голубым цветом
- Сайт в формате мобильного приложения (mobile-first дизайн)
- В шапке сайта отображается: «magazin-tour. Магазин туров и активностей»
- Администратор может выбирать для каждой активности: отправлять на страницу оплаты либо на форму заказа (ползунок в настройках активности)
- Email-уведомления: письмо с регистрационными данными клиенту, письмо с данными бронирования администратору
- Администратор может добавить несколько email-ящиков для получения уведомлений
- Основные данные (email-ящики, настройки) редактируются на специальной странице в админ-панели
- Для активностей 18+ на странице активности показывается плашка с вопросом «Есть ли вам 18 лет?» и кнопками Да/Нет. При выборе «Да» плашка скрывается и показывается содержимое. При выборе «Нет» — перенаправление на главную страницу
- ID разделов и активностей автоматически генерируются в транслитерации из названия (русские буквы → латиница)
- Цена для партнёра — скрытое поле, видимое только в админ-панели. Клиент видит только цену для клиента. При оплате списывается цена для партнёра
- Главный администратор artkmv1@ya.ru имеет полный доступ. Дополнительные администраторы — только к активностям и разделам
